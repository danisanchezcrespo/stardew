# Playtest fixes — 2026-09-03

- Save/load moved from editor-reserved F5/F9 to K/L and save writes are atomic.
- Completed crates, kilns, dwellings and shrines render dedicated original art.
- Placement ghost follows the walking character and cannot be moved remotely.
- Crafting uses a warm high-contrast panel with one clickable button per recipe.
- Multi-cell structures select the nearest footprint cell for interaction.
- Route creation consumes two reliable R presses, keeps source feedback visible,
  marks the selected source, and reports invalid targets explicitly.
- Crafting confirmation uses Enter rather than overloading world interaction E.
- Selecting a placeable quick-slot item immediately enters ghost placement mode.
