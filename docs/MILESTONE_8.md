# Milestone 8: physical construction

Status: implementation complete; visual walkthrough pending.

## Outcome

Placing a building plan creates a physical construction site. The player must
carry its required materials to the site and then perform local work before the
building becomes complete.

## Progress

- [x] Data-defined construction costs and work duration.
- [x] Craftable and placeable Brick Kiln plan.
- [x] Construction-site material ledger.
- [x] Contextual material delivery from selected inventory stack.
- [x] Held local work action with visible progress.
- [x] Completion transition without changing spatial identity.
- [x] Inventory-safe rejected delivery and construction actions.
- [x] Automated craft, place, supply, work and completion test.
- [ ] Visual acceptance walkthrough.
