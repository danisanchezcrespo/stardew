# Milestone 12: maintenance, breakdowns and recovery

Status: in progress.

## Outcome

Working machines lose durability after completed batches. A broken machine stops
without losing stored items, displays a clear fault state, and can be restored
locally by carrying the required repair material.

## Progress

- [x] Deterministic per-batch durability wear.
- [x] Safe broken-state production pause.
- [x] Distinct broken building colour and contextual guidance.
- [x] Transaction-safe local repair using Wood x2.
- [x] Queued-input recovery after repair.
- [x] Automated wear, fault and recovery test.
- [ ] Visual acceptance walkthrough.
