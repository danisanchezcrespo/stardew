# Milestone 9: physical machines and visible production

Status: in progress.

## Outcome

A completed Brick Kiln accepts appropriate items carried by the player, runs a
timed recipe in the world, visibly signals activity, stores its output and lets
the player collect the result locally.

## Progress

- [x] Data-defined kiln recipe and processing duration.
- [x] Per-instance input and output inventories.
- [x] Transaction-safe contextual input delivery.
- [x] Timed batches with capacity checks.
- [x] Running-state world feedback and contextual progress text.
- [x] Local output collection into player inventory.
- [x] Local diagnostic panel for recipe, inventory, staffing and durability.
- [x] Automated build, supply, process and collect test.
- [ ] Visual acceptance walkthrough.
